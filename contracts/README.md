# GSPD Smart Contracts

## Contracts

### GSPDERC20.sol
GRC20 token implementation for the GSPD blockchain.

### GSPDFactory.sol
Creates new liquidity pairs.

### GSPDPair.sol
Liquidity pool contract.

### GSPDRouter.sol
Router contract for:
- Swap
- Add Liquidity
- Remove Liquidity

## Directories

### interfaces/
Smart contract interfaces.

### libraries/
Shared libraries used by the contracts.
